Pipeline RAG completa: Ingestão, Consulta e Obserabilidade

Este projeto demonstra a construção de um pipeline de Recuperação e Geração Aumentada (RAG) completo, focado em uma aplicação jurídica capaz de responder perguntas sobre súmulas do Tribunal de Contas de Minas Gerais (TCEMG) a partir de documentos PDF. Desenvolvi um sistema que não apenas recupera informações relevantes, mas também as gera de forma coerente e contextualizada, lidando com desafios como a normalização de datas para filtros eficazes. Este trabalho destaca minha capacidade em integrar tecnologias de ponta para criar soluções escaláveis e inteligentes no campo de LLMs e processamento de documentos.

As ferramentas utilizadas foram:

  • LangChain;
  • LangGraph;
  • Langfuse;
  • Qdrant;
  • Streamlit.
