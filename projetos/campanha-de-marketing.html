Campanha de Marketing

Projeto de análise preditiva para treinamento de modelos e dashboard. Este projeto contém um pipeline para treinamento de modelos de Machine Learning e um dashboard desenvolvido em Streamlit para visualização e integração dos dados, permitindo acompanhar métricas, previsões e resultados de forma interativa.
